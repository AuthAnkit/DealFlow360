Demo data set

A real base catalog (~450 products, 60 customers, 8 sales reps) built through the real quotation/approval/fulfillment/billing services. Loads automatically on a fresh database; use this on a database that already existed. Everything past the base is manual - add exactly as many quotations, extra products, extra customers and extra reps as you want, as many times as you want, to grow the set to any size (1000+, 5000+, whatever you need).

-

The first run also builds the base catalog (skipped by name/username on later runs, so it never duplicates). Every field above is optional and purely additive - leave any at 0 to skip it, or run this repeatedly with big numbers (e.g. quotations=1000, extra customers=1000, extra products=700) to push every category past 1000 yourself.

Tier price lists (A2 - customer tier based pricing)

A tier price replaces the catalog price for customers of that tier when a line is added to a quotation. Products without a row use the catalog price. Discounts on top are still governed by the discount ceilings.
